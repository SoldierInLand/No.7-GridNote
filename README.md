# GridNote

A structural-grid notebook for arranging rich-text notes, shapes, drawings, and tables on flexible pages.

## Local development

Requires Node.js 22 or newer.

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Production build

```bash
npm run build
```

Small changes are reviewed locally. Completed milestones are pushed to GitHub and deployed through Vercel.
